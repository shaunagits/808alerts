Marks described, not drawn: none added. No icons, illustrations or motifs anywhere in these mocks.

Glyphs: basic Latin plus &#8594; only. The back link carries no arrow: the shipped detail views use a left arrow, and U+2190 was never confirmed present in the subset the way U+2192 was, so drawing one here would risk the okina trap a second time. Confirm U+2190 against the built subset and I will add it back; the label alone works either way. The okina in these mocks renders as the left single quote exactly as the shipped subset does. Source strings keep U+02BB.

Font: these files declare Archivo and fall back to the system stack, since nothing external may load. In the live file the inlined subset covers it; Archivo Narrow is the wdth 77% axis, which is what font-stretch:77% stands in for here.

Off-palette values used: only #3a3a3a, the shipped hero input border, treated as an ink variant. Board chrome around the mocks is deliberately grey so it cannot be mistaken for the design. The needs-verification band uses --advis on the precedent of the existing discrepancy notes, not as a severity step.
